What is OpenCode?

OpenCode is an open source agent that helps you write code in your terminal, IDE, or desktop.

[*] LSP enabled — Automatically loads the right LSPs for the LLM
[*] Multi-session — Start multiple agents in parallel on the same project
[*] Share links — Share a link to any session for reference or to debug
[*] GitHub Copilot — Log in with GitHub to use your Copilot account
[*] ChatGPT Plus/Pro — Log in with OpenAI to use your ChatGPT Plus or Pro account
[*] Any model — 75+ LLM providers through Models.dev, including local models
[*] Any editor — Available as a terminal interface, desktop app, and IDE extension

Frequently Asked Questions

1. What is OpenCode? +

OpenCode is an open source AI coding agent designed to run autonomously in developer environments, terminal sessions, and desktop editors.

2. How do I use OpenCode? +

Install the CLI via curl or package managers, navigate to your project directory, and run the `opencode` command followed by natural language instructions.

3. Do I need extra AI subscriptions to use OpenCode? +

No. OpenCode includes access to free validated models out of the box with zero setup.

4. Can I use my existing AI subscriptions with OpenCode? +

Yes. You can seamlessly authenticate with your GitHub Copilot, OpenAI ChatGPT Plus/Pro, Anthropic, or Gemini credentials.

5. Can I only use OpenCode in the terminal? +

No. OpenCode is built as a versatile core agent accessible via standard CLI, standalone desktop app, and IDE extensions.

6. How much does OpenCode cost? +

The core platform is completely free and licensed under open source terms.

7. What about data and privacy? +

OpenCode executes locally or direct-to-API with zero telemetry on source files and strict non-retention policies.

8. Is OpenCode open source? +

Yes, 100% of the agent engine, runtime, and harness architecture is publicly inspectable and governed on GitHub.
