FAQ

What is Claude and how does it work?

Claude is an AI assistant developed by Anthropic, built on Constitutional AI to be helpful, harmless, and honest. It is capable of sophisticated writing, complex code generation, document analysis, multi-agent collaboration, and logical problem solving.

What should I use Claude for?

People use Claude across coding, writing, research, and analysis. From running full multi-file software builds via Claude Code and Cowork to drafting nuanced executive communications, translating technical papers, and synthesizing massive databases of documentation.

How much does it cost to use?

Claude is free to use on web and mobile with access to standard features. For professionals requiring heavier usage, extended model thinking, Claude Code, and project workspaces, Claude Pro is $23/month billed annually ($28/month billed monthly), and Claude Max starts at $140/month.
