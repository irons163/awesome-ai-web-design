from openai import OpenAI
from composio_openai import ComposioToolSet, Action, App

client = OpenAI()
composio_toolset = ComposioToolSet(entity_id="dev_user_449")

# Pull verified actions across connected software
tools = composio_toolset.get_tools(apps=[App.GITHUB, App.SLACK, App.NOTION])

response = client.chat.completions.create(
    model="gpt-4o",
    tools=tools,
    messages=[{"role": "user", "content": "Star the composio repo and post confirmation in Slack"}]
)

result = composio_toolset.handle_tool_calls(response)
print("Action Execution Complete:", result)

[ FAQ ]

Frequently asked questions

How does Composio compare to raw LangChain tools or custom API scripts? +
Raw tools require you to manually write OAuth redirect flows, keep access tokens fresh, maintain updated JSON schemas, and feed thousands of prompt tokens per request. Composio acts as a managed runtime that handles token vaults, dynamic 90%+ schema compression, self-healing execution, and 1,500+ pre-built integrations natively.
How is user authentication handled? +
Composio provides hosted user auth connect URLs and a headless API. When an end-user connects their account (e.g. GitHub or Google Drive), Composio securely handles the OAuth handshake, stores the token in dedicated KMS-encrypted envelopes, and auto-refreshes tokens without exposing keys to LLMs.
What is context bloat and how does Composio solve it? +
Supplying complete OpenAPI documentation for multiple applications consumes tens of thousands of tokens before user prompts even start, triggering LLM hallucinations and high costs. Composio’s semantic indexing filters only the 3-5 necessary tools dynamically based on user intent.
Is there a free tier for developers? +
Yes. Every developer gets 100,000 free action executions each month, unlimited integrations, managed auth, and access to Python and TypeScript SDKs without requiring a credit card.
