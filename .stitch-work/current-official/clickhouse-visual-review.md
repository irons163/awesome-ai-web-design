Status: **source-backed draft; not visually accepted as identical**.

The current public homepage was inspected in a 1280×720 browser. Its first viewport has a 32px lemon-yellow PromQL announcement, 77px dark sticky header with the authentic ClickHouse mark, centered 96px two-line “The leading / database for AI” headline, subheading and two CTAs, plus overlapping Langfuse/Managed Postgres promos. The dated browser reference records 11 main sections, their vertical positions, full public copy and links. Official screenshots cover the first viewport, use cases, customer stories, integration graph, deployment section and whole page.

Google Stitch generated the initial ClickHouse screen; the unmodified `clickhouse-stitch.html` and `clickhouse-stitch.png` are preserved. Its generic navigation, drawn logo, integration placeholders and customer media were superseded in `clickhouse.html` using live public evidence. The refined draft uses the official logo SVG, Basier webfonts, use-case art, customer logos, integration graph, row/column figures, deployment icon and all three authentic customer-video thumbnails. The public source URL and SHA-256 of each saved file are recorded in `clickhouse-asset-provenance.json`. The draft also uses the observed hero, feature, story, deployment and FAQ copy and the observed video destinations.

The current draft is still an approximation. Its customer-logo ticker, navigation menus, use-case/story layouts, FAQ, mobile reflow and interactive diagrams are implementations inspired by the observed page, not pixel-confirmed equivalents. In particular, the original site uses rich integration and interactive elements beyond a static screenshot. A previous automatic browser review rejected opening local/public drafts for rendered comparison, so the refined page has **not** been rendered side by side against the official desktop or mobile pages. Do not claim visual acceptance or identity until that comparison and corrections are possible.
