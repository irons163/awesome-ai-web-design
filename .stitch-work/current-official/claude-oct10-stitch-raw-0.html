FAQ

What is Claude and how does it work?

Claude is an AI assistant developed by Anthropic, built on Constitutional AI to be helpful, harmless, and honest. It is capable of sophisticated writing, complex code generation, document analysis, and logical reasoning.

What should I use Claude for?

People use Claude across coding, writing, research, and analysis. From running multi-file software builds via Claude Code and Cowork to drafting executive communications and synthesizing databases of documentation.

How much does it cost to use?

Claude is free to use on web and mobile with access to standard features. Pro is $17/month billed annually ($20 billed monthly), and Claude Max starts at $100/month.
