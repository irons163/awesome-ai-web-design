Developer Workflow

How it works

From running public models to custom fine-tunes and packaging your own weights with Cog — Replicate handles cold starts, GPU orchestration, and scaling.

01 / RUN MODELS

Run any model with a simple API call

No need to configure CUDA drivers, Docker daemons, or rent idle A100s. Just send JSON inputs and receive predictions over fast websockets or webhooks.

// Run via cURL or any standard HTTP client
curl -s -X POST \
  https://api.replicate.com/v1/predictions \
  -H "Authorization: Bearer $REPLICATE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"version": "504c483f...", "input": {"prompt": "cyberpunk portrait"}}'
• Client libraries in 6+ languages • Webhooks & streaming
02 / FINE-TUNE MODELS

Train models on your own datasets

Upload a zip of images or text tokens. Replicate spins up dedicated H100 GPU clusters, trains LoRAs or full checkpoints, and publishes a private model destination for your team.

03 / DEPLOY WITH COG

Package any PyTorch code with Cog

Cog is an open-source tool that lets you containerize machine learning models. Define Python requirements and system packages in a clean YAML file; Cog generates an optimized Docker container and API server.

# cog.yaml — define CUDA, dependencies & weights
build:
  gpu: true
  cuda: "12.1"
  python_version: "3.11"
predict: "predict.py:Predictor"
