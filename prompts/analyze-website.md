# 從公開網站建立 DESIGN.md

```text
請分析我提供的網站或截圖，建立可讓開發工具使用的 DESIGN.md。
先列出實際觀察的頁面、日期、畫面尺寸與資料限制。若無法開啟頁面，請要求我補充截圖，不要把推測當成觀察。

把觀察整理成：整體視覺方向、具語意的色彩角色、字體與替代字體、字級層級、間距與網格、元件結構、互動狀態、響應式規則及可用性要求。
每個 token 都要有用途；只有實際取得的數值才能標成精確值。無法確認的字體、色碼、斷點或動畫要標示為建議值。

用元件的結構與資訊層級解釋設計，不要只列形容詞。分別說明預設、焦點、停用、載入、空白和錯誤狀態。圖片與品牌資產只記錄需求，不複製受限制的素材。
最後附上最小頁面組成範例、需要進一步確認的項目，以及桌面與手機的驗收方式。
```
