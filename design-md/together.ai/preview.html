05 / THREE-STEP INTEGRATION

Native drop-in protocol integration

Zero-dependency client libraries and 100% wire compatibility with the OpenAI SDK specification.

01

Install client

Install via your standard package manager. Fully typed with autocompletion for all models and parameter schemes.

pip install nexus-infer
02

Initialize provider

Point your existing OpenAI library directly to the Nexus base URL or instantiate our native thin client.

base_url="https://api.nexusinfer.com/v1"
03

Stream with zero cold-starts

All enterprise endpoints remain permanently hot on physical H100 partitions without autoscaling pauses.

stream = client.chat.create(..., stream=True)
